# Road Risk Assessment

Professional road risk assessment tool for Mosaic Forest Management.

## v2.8.0 Features
- EGBC/FPBC 3.7.2 Inspection Compliance
- Section 11 WSA Notification  
- Full CSV Export
- Edit Saved Assessments
- Auto-Date Calculation
- Multi-Segment Assessment
- QuickCapture Integration
- Offline PWA

## Quick Start
```bash
npm install
npm start
```

## Build
```bash
npm run build
```

Builds to `/build` directory for deployment.
